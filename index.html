Minecraft Java 26.2 required. Select version 26.2 in your launcher before joining.

Start server ↗

Opens Falix in a new tab. Press Start there, then wait for it to finish.

  1. Open Minecraft Java 26.2. In the launcher: Installations → New installation → version 26.2.
  2. Go to Multiplayer → Add Server and paste the address.
  3. Join and accept the server resource pack.

Download OptiFine for 26.2 ↗
Optional. Official K2 pre5 preview build. You can join without it.

Do I need to install anything?

Use Minecraft Java 26.2 on a computer. No modpack or mod loader is required. Accept the resource-pack download when you join.

Server still offline?

Keep the Falix start tab open. You may need to complete a CAPTCHA or wait in a queue. Once startup finishes, refresh your Minecraft server list and try again. Already online? Join directly.

What's different?

We use Matcha Flavoured for more casual progression. Build a home, explore, and work on the town at your own pace.
